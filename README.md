## Запуск

Требуется Go 1.22 или новее. Внешних библиотек нет. Проверено на Go 1.27.0 linux/amd64.
Из папки проекта:

```sh
go run ./cmd/linear
go run ./cmd/modular
```

Вводите по одной команде в строке:

```text
+ А101ВР36
+ В202МТ36
- А101ВР36
list
exit
```

`+ НОМЕР` — прибытие, `- НОМЕР` — окончательный выезд, `list` — вывод от дальнего конца к выезду, `exit` — завершение. Номер — непустая строка без пробелов; регистр значим, формат государственного номера не проверяется. Повторный номер на стоянке запрещён. Пустые строки игнорируются. Конец ввода завершает программу. При новой парковке после окончательного выезда счётчик начинается с нуля. Данные хранятся только в памяти, вместимость условно не ограничена. Слишком длинная строка (предел bufio.Scanner около 64 КиБ) приводит к сообщению об ошибке и коду завершения 1.

```sh
go run ./cmd/modular < testdata/demo.txt
go test -v ./...
go vet ./...
go run ./cmd/halstead cmd/linear/main.go cmd/modular/main.go > results/metrics.json
```


## Состав

- `cmd/linear/main.go` — монолитная версия, вся логика в main.
- `cmd/modular/main.go` — функции find, arrive, depart, show и main.
- `cmd/halstead/` — анализатор и его тесты.
- `tests/` — проверка обеих программ по ожидаемым результатам.
- `testdata/` — контрольный ввод и эталонный вывод.
- `results/metrics.json` — полные словари и вычисленные показатели.
- `results/tests.txt` — фактический протокол тестирования.
- `results/demo.txt` — фактический контрольный вывод модульной версии.
- `results/operators.tsv`, `results/operands.tsv` — сравнительные таблицы частот.
